## Project Overview

Run Mapper is a Python project. The codebase is currently in early development.

## Development Environment

- Python 3.9+
- Dependencies managed with [Poetry](https://python-poetry.org/)

## Common Commands

- Install dependencies: `poetry install`
- Add a dependency: `poetry add <package>`
- Add a dev dependency: `poetry add --group dev <package>`
- Run a command in the virtualenv: `poetry run <command>`
- Activate the virtualenv: `poetry shell`
