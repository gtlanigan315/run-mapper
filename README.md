# Run Mapper

A Python application for mapping runs.

## Requirements

- Python 3.9+
- [Poetry](https://python-poetry.org/)

## Setup

1. Install dependencies:
   ```bash
   poetry install
   ```

2. Activate the virtual environment:
   ```bash
   poetry shell
   ```

   Or run commands directly with:
   ```bash
   poetry run <command>
   ```
